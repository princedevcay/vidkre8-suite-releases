# VidKre8 Suite: downloads

VidKre8 Suite is a free app for Mac and Windows. You can trim, join, convert and clean up video and audio files on your own computer. It never goes on the internet and never changes your original files.

**Download it from the download page,** which explains each step in plain words. You can also go straight to [the latest release](../../releases/latest).

This repository only holds the release files: the installers, their SHA-256 fingerprints, the licences and the ffmpeg source code. The app's own source code is not public.

- **Licences:** VidKre8 Suite includes ffmpeg, free software shared under the GNU GPL version 3. The licence, the notices and the exact ffmpeg source are attached to every release.
- **Security problems:** see [SECURITY.md](SECURITY.md).

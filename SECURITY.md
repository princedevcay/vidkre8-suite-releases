# Reporting a security problem

If you find a security problem in VidKre8 Suite, please report it privately. Use **Security → Report a vulnerability** on this repository: <https://github.com/princedevcay/vidkre8-suite-releases/security/advisories/new>.

Please don't open a public issue for it.

- You'll get a reply within 7 days.
- Problems are fixed within 30 days, in a new release on this repository.
- Only the latest version is supported, so please check that you have it.

VidKre8 Suite never goes on the internet. To get a fix, download the new version from the download page.
